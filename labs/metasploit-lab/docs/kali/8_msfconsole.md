# `msfconsole`

Metasploit is primarily used through a command-line program started with `msfconsole`. 

It provides a way to search, select, and configure exploit modules.

Commands of use:

  - `search`: Look for exploitation modules
  - `use`: Load an exploit module
  - `info`:` Look at module information

Try searching for Tomcat exploits with `search tomcat`.
