# What is Malleus?

Malleus is a framework for creating and operating lightweight self-hosted digital labs and workshops for learning server administration, cybersecurity, and more! It utilizes the [Incus](https://linuxcontainers.org/incus/) container and virtual machine management system with a web-based user interface to allow students to quickly instantiate personal labs with minimal overhead. Students can then access the labs **with only a browser**, enabling terminal access to systems without special tools. 

# Why Malleus?

Malleus was originally built to make cyber-workshops easier to run without requiring students to do extensive preparation (college students notoriously don't do the prep work...). A instructor can just walk in with a laptop with Malleus installed, students can just log in and get started working on the lab immediately. With built-in documentation capabilities, students can work at their own pace on the labs and have handy reference material on-hand during the exercises. 

Malleus also focuses on making labs easy to construct and share. It utilizes a file-based structure to make distribution, modification, and collaboration simple without complex scripts.
